Specialist: Agent Behaviour Policies

Status: first run done, 16 November 2026

The home of specialist.abp@AgentiCCells.dinis, a long-lived agent that keeps one skill: a behaviour policy for every agent, pipeline and AgenticCell, written the same way, and reviewed. It is a consultant to every other team. It never does another team's work. Its person is Dinis Cruz.

The idea is set out in Specialist agents for every team. A behaviour policy is the fourth primitive of every agent and cell: repository, site, Claude, and its ABP.

Start here

The day-one pack
One format, templates for an agent, a pipeline and an AgenticCell, and how to move from observe to enforce. A checker, scripts/abp-check.mjs, refuses a policy that is not written the same way, and counts how much of it is a boundary and how much is hope.
Guidance
26 principles, each with its source and an example, compressed from the newsroom, the Web Summit team's 93 policies, PrompTugal.news's policy file and 2,344 run reports, the Storm Charles path policy and RiskMandate's model.
Mistakes
What went wrong before and why, starting with the push to main on 2 November, a rule that failed because it was only a rule, and the fact that every policy we run is in observe mode.
Examples
The best policies we have, with links, and what each does well.
